🏥 Medical Camp Registration Portal

A responsive web-based application that allows users to view available medical camps and register for participation.

📌 Project Overview

The Medical Camp Registration Portal is developed as part of the Sysslan IT Solutions Software Development Internship.

The application provides a simple end-to-end flow where users can:

- View available medical camps
- Check camp dates and locations
- Register for a medical camp
- Validate registration details
- View registered participants
- Manage participant records

The project focuses on clean UI structure, smooth navigation, responsiveness, basic data handling, and usability.

🎯 Objectives

- Display medical camp information clearly
- Allow users to register for camps easily
- Store and manage participant data
- Ensure responsiveness and usability
- Deliver a complete functional mini web application

✨ Features

🏠 Home

Provides an introduction to the Medical Camp Registration Portal and explains its purpose.

🏥 Camp Details

Displays multiple medical camps with:

- Camp Name
- Date
- Location

📝 Registration

Users can register by providing:

- Full Name
- Age
- Contact Number
- Medical Camp Selection

✅ Form Validation

The application validates:

- Required fields
- Age between 1 and 120
- Valid 10-digit contact number

🎉 Registration Confirmation

After successful registration, the application displays a confirmation message to the user.

👨‍💻 Admin View

The Admin section allows registered participant information to be viewed.

🗑️ Delete Participant

Registered participant records can be deleted with confirmation.

💾 Data Storage

Participant registration data is stored using the browser's localStorage.

📱 Responsive Design

The interface adapts to:

- Desktop
- Tablet
- Mobile devices
